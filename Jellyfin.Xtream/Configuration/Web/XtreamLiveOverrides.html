Custom EPG

This changes guide data only. Live TV streams continue to use Xtream exactly as before.
Enter an http(s) URL (downloaded and cached for a day, gzip supported) or a local path that the Jellyfin server process can read. Channels are matched automatically by the provider's EPG id, then by name; set an XMLTV id below only to correct a match. Save once after changing this path, then reopen TV Overrides so the channel-id suggestions can be loaded.

TV channel overrides

For Custom XMLTV, map each Xtream channel to the XMLTV <channel id="...">. The mapping affects guide data only. Use EPG shift when a channel's guide is off by a fixed amount (for example -1 h, or 0 h 30 min); it moves both Xtream and XMLTV programmes, and empty or 0 leaves the times unchanged.
